# arcrun-port — Arcrun 的地端接口（桌面小幫手 / Arcrun App）

> **這個 repo 是桌面那一端的家：原始碼、版本說明、每一版的安裝檔，全部在這裡。**
>
> - **要下載** → 右邊的 **Releases**，最新一版就是最上面那筆。
>   每一筆都掛著當版的三個成品：macOS 的 `.dmg`、Windows 的 `.exe` 與 `.msix`。
> - **這一版改了什麼** → 同一筆 release 的內文，原稿是 [`CHANGELOG.md`](CHANGELOG.md)。
> - **版本號長什麼樣** → `0.18.x`（[`DAEMON_LINE`](DAEMON_LINE) 宣告的那條線）。
>   雲端引擎是 `1.4.x`，**是另一個產品、另一個 repo**（見下）。

## 為什麼叫 `port` 而不是 `collector`

它不只是收集器。**它是 Arcrun 雲端與地端之間的那個口**——

- 往上：把你電腦上的資料夾變成知識庫，同步進雲端引擎
- 往下：讓你在桌面上直接用（App 界面、寫筆記、看整理結果），不必開瀏覽器
- 兩邊：認得出資料夾搬過家、幫你把它放進去的隱藏檔清乾淨

`collector` 只描述它做的其中一件事。名字要講**角色**，不要講其中一個功能。

## 跟 arcrun-rag 的關係

[`youlinhsieh/arcrun-rag`](https://github.com/youlinhsieh/arcrun-rag) 是**雲端引擎**（`1.4.x`）
——跑在你自己 Cloudflare 帳號上的那些 worker。桌面這端會連上它，
但兩者是**兩個產品、兩條版本線、兩份版本說明**。

🔴 **為什麼分開**：在此之前兩個產品的版本發佈疊在同一條歷史上
（`0.18.33`、`0.18.30` 跟 `1.4.49`、`1.4.48` 並排），出貨線每跑一次就多疊一筆。
兩個產品共用一條版本歷史，「最新版是哪一個」就沒有答案。

## 這個 repo 怎麼來的

原始碼的真相源在 [`git.uncle6.me`](https://git.uncle6.me) 上的開發庫，
出貨時把桌面那端的原始碼同步過來，並在這裡建一筆版本發佈。
⇒ **不要直接在這裡改東西**，下一次同步會蓋掉。

`README.md` 與 `.gitignore` 是例外——它們由這個 repo 自己維護，同步時不覆蓋、也不刪除。
